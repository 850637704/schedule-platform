# 课表管理平台使用文档编写计划

## Context
用户需要一份面向最终用户的使用文档，帮助不同角色（超管、管理员、教师）了解如何操作课表管理平台。文档需覆盖所有功能模块的操作流程和注意事项。

## 目标文件
创建 `使用文档.md`，放在项目根目录。

## 文档结构

### 1. 系统简介
- 平台用途、技术栈简述、访问方式（localhost:3000 / 局域网 IP）

### 2. 用户角色与权限
- 超级管理员：全部权限（上传、调课、账号管理、Logo更换、导出等）
- 管理员：除账号管理外的全部权限
- 教师（未登录）：查看课表、课时统计、冲突分析、导出、查看调课候选

### 3. 登录系统
- 登录入口、记住账号密码功能、退出登录
- 超管初始账号、密码重置方式

### 4. 上传课表
- Excel 工作簿格式要求（8 个工作表说明）
- 上传操作步骤（拖拽/点击选择）
- 模板下载
- 上传成功后的数据展示

### 5. 总览页面
- 统计卡片说明（单周记录数、班级数、教师数、科目数）
- 教师安排表查看与聚光灯功能
- 导出按钮（全部班级课表、全部教师课表、教师安排 Excel、教师安排图片）

### 6. 班级课表
- 周次切换、班级选择
- 课表网格查看、任课教师表、时段显示
- 聚光灯高亮
- 导出 Excel / 导出图片

### 7. 教师课表
- 教师选择、课表查看
- 重课单元格半格显示
- 冲突高亮（重课红色、会议橙色、调休紫色）
- 导出 Excel / 导出图片

### 8. 课表调整（调课）
- 教师模式 vs 班级模式
- 选择源课程 → 查看可调目标 → 执行对调
- 冲突校验说明（5 层校验）
- 多步撤销
- 调课记录查看
- 对周同步说明（高一/高二关联科目）

### 9. 课时统计
- 教师统计 vs 班级统计
- 筛选框使用
- 统计列说明（早自习、白课、晚自习、班会、自习、周课时等）
- 导出 Excel

### 10. 冲突分析
- 运行分析操作
- 冲突类型说明（重课、会议、调休）
- 汇总卡片与详情列表

### 11. 账号管理（仅超管）
- 管理员账号增删
- 密码重置
- 超管密码管理（多密码、永久密码）

### 12. Logo 更换（仅超管）
- 点击图标上传图片

### 13. 常见问题
- 上传失败排查
- 数据隔离说明
- 浏览器兼容性

## 参考文件
- `public/index.html` — 页面结构和导航
- `public/js/app.js` — 交互逻辑
- `server.js` — API 端点
- `utils/` — 各功能模块
- `更新日志.md` — 历史变更记录

## 验证方式
- 通读文档，确保每个功能模块都有操作说明
- 对照实际界面验证操作步骤准确性
